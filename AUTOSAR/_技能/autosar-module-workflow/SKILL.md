# AUTOSAR 模块标准化工作流（通用技能）

## 1. 何时使用

- 需要维护任意模块的《<模块名>标准化流程.xlsx》（CanNm 已建成，EcuM/Com 等复用）；
- 需要给新模块生成流程工作簿骨架（复制 → 替换模块名 → 清空模块内容 → 刷新甘特）；
- 需要校验工作簿结构、日期、ID、枚举、隐私、数据验证与甘特视图；
- 需要把学习成果（需求表、调用逻辑、测试）纳入过程管理。

> 本技能是通用版；CanNm 专用版已删除，其经验（结构/规则/校验/踩坑）全部收敛到这里。

## 3. 工作簿结构（15 个 Sheet，名称固定）

`0-使用说明`、`0a-目录说明`、`1-文件变更履历`、`2-流程总览`、`3-开发计划`、`4-需求追溯矩阵`、`5-差异台账`、`6-测试用例与CAPL`、`7-问题台账`、`8-评审记录`、`9-变更记录`、`10-基线清单`、`11-能力分析`、`12-术语与参考`、`13-甘特视图`。

列定义见 `references/workbook-schema.md`。修改时不得重命名/删除 Sheet；新增需同步 `0a-目录说明` 与 `0-使用说明`。

## 4. ID / 状态 / 日期规则

- ID 前缀：`PLAN-` / `REQ-` / `BL-` / `DIF-` / `TC-` / `Q-` / `G0~G6` / `CR-`。
- 需求号：`SWS_<模块名>_xxxxx`；配置参数：`ECUC_<模块名>_xxxxx`；追溯：`RS_/SRS_*`。
- 状态字典：计划 / 进行中 / 待评审 / 完成 / 阻塞 / 挂起。
- 评审结论：通过 / 有条件通过 / 不通过 / 待评审。
- 差异类型：可选特性未实现 / 实现偏差 / OEM特殊需求 / 工具链限制。
- 日期必须是 Excel 日期类型，禁止字符串（历史错误示例 `207/1/20`）。

## 5. 更新流程

1. **每周**：更新 `3-开发计划` 实际日期、进度（0~1）、状态、风险；甘特视图会随之刷新。
2. **评审门后（G0~G6）**：更新 `8-评审记录`；遗留问题进 `7-问题台账`/`5-差异台账`；`9-变更记录` 登记 CR；必要时 `10-基线清单` 冻结。
3. **需求变化**：先改 Obsidian 需求表（需求号锚点），再同步 `4-需求追溯矩阵` 与 `5-差异台账`。
4. **测试进展**：`6-测试用例与CAPL` 填执行结果/状态；失败项进问题台账。
5. **收尾**：`1-文件变更履历` 加版本行；`11-能力分析` 更新差距；`12-术语与参考` 补文档。

## 6. 新模块实例化（EcuM/Com 等）

```bash
# 1) 复制并替换模块名、清空模块内容、重建甘特
python AUTOSAR/_技能/autosar-module-workflow/scripts/instantiate_workbook.py \
  --source "AUTOSAR/00_学习路线/CANNM标准化流程.xlsx" \
  --target "AUTOSAR/00_学习路线/EcuM标准化流程.xlsx" \
  --module EcuM

# 2) 校验
python AUTOSAR/_技能/autosar-module-workflow/scripts/validate_workbook.py \
  "AUTOSAR/00_学习路线/EcuM标准化流程.xlsx" --module EcuM

# 3) 计划日期/基线按项目填写后，刷新甘特
python AUTOSAR/_技能/autosar-module-workflow/scripts/refresh_gantt.py \
  "AUTOSAR/00_学习路线/EcuM标准化流程.xlsx" --module EcuM
```

实例化脚本会：替换 `CanNm/CANNM` → `<模块名>/<MODULE>`；清空需求追溯/差异/用例/问题/基线中的 CanNm 行并写入模板行；保留 P0~P6 计划结构；重建甘特。详见 `references/instantiation-guide.md`。

## 7. 编辑规范

- 用 **openpyxl** 修改；用 Python 脚本，**不要用 PowerShell `Set-Content` 处理含中文的脚本**（会破坏编码，本项目已发生过）。
- 默认另存新版本（如 `_V0.03.xlsx`）；修改前备份；保留标题合并、表头样式、冻结、筛选、数据验证、条件格式。
- 不写入手机号/邮箱、项目敏感问题；原 OIL/成员清单不迁入。
- 日期用 `datetime.date` + `yyyy-mm-dd` 格式；进度用 0~1 + `0%`。
- 新增行后扩展数据验证范围与甘特行。

## 8. 校验

```bash
python AUTOSAR/_技能/autosar-module-workflow/scripts/validate_workbook.py \
  "AUTOSAR/00_学习路线/CANNM标准化流程.xlsx" --module CanNm
```

检查：15 个 Sheet、计划表头/日期/进度/状态、需求号前缀与唯一性、枚举值、`#REF!`、隐私字段、数据验证、甘特视图存在性与周列数。全部 PASS 才完成。

## 9. 已知坑

1. PowerShell 文本重写损坏中文 Python 脚本 → 改脚本用 Python/编辑工具。
2. 原学习计划 `A样开发计划!F24 = "207/1/20"`、`OIL表!A1 = =#REF!&...`：新工作簿已不复制这些错误。
3. 标题合并需覆盖整表宽度，否则标题截断。
4. 数据验证范围要随后续新增行扩展。
5. 日期不设 `yyyy-mm-dd` 会显示序列号。
6. 甘特视图依赖 `3-开发计划` 的 I/J 列日期；改日期后必须刷新甘特。
7. 敏感信息：成员清单/手机号/邮箱默认不迁入。
